# Amora

A modern React application with a beautiful color palette inspired by [this color hunt](https://colorhunt.co/palette/c7db9cfff0bdfdab9ee50046).

## 🎨 Color Palette

The application uses a carefully selected color scheme:

- `#C7DB9C` - A soft sage green
- `#FFF0BD` - A warm cream
- `#FDAB9E` - A soft coral
- `#E50046` - A vibrant red

## 🚀 Tech Stack

- **Frontend**: React 19 with TypeScript
- **Backend**: Convex
- **Styling**: Tailwind CSS
- **Routing**: TanStack Router
- **State Management**: TanStack Query
- **UI Components**: Radix UI
- **Build Tool**: Vinxi

## 📦 Prerequisites

- Node.js (Latest LTS version recommended)
- pnpm (Package manager)

## 🛠️ Installation

1. Clone the repository:

```zsh
git clone https://github.com/yourusername/amora.git
cd amora
```

2. Install dependencies:

```zsh
pnpm install
```

3. Set up environment variables:

```zsh
cp .env.example .env.local
```

Edit `.env.local` with your configuration.

## 🚀 Development

Start the development server:

```bash
pnpm dev
```

This will start both the frontend and backend servers in parallel.

## 📝 Available Scripts

- `pnpm dev` - Start development servers (frontend and backend)
- `pnpm build` - Build the application
- `pnpm start` - Start the production server
- `pnpm typecheck` - Run TypeScript type checking
- `pnpm lint` - Run ESLint
